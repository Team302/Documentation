# Machine Learning

Machine Learing in vision is when we utilize a machine learing model that is used by a veision solution, ex. limelight.
machine laering models are made by taking a large group of images and 'training' a model to recognize them, for a model
to be accurate it may sometimes need thousands of images.
limelight has some documentation here:
https://docs.limelightvision.io/docs/docs-limelight/pipeline-neural/training-your-own-detector
